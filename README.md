🧪 Testes de Software

Conhecimento em diferentes tipos de testes para validar funcionalidades, verificar regras de negócio, identificar falhas e aumentar a confiabilidade das aplicações.

🔍 Tipos de Testes

Tipo de Teste| Objetivo
✅ Testes Funcionais| Verificar se as funcionalidades atendem aos requisitos.
🔗 Testes de Integração| Validar a comunicação entre componentes e sistemas.
🌐 Testes de API| Verificar requisições, respostas, códigos HTTP e tratamento de erros.
🔄 Testes de Regressão| Garantir que alterações não afetem funcionalidades existentes.
🚀 Testes End-to-End (E2E)| Validar fluxos completos de utilização da aplicação.
💨 Testes de Fumaça (Smoke Tests)| Verificar se as funcionalidades essenciais estão operacionais.
🩺 Testes de Sanidade (Sanity Tests)| Verificar pontualmente alterações ou correções específicas.
🔎 Testes Exploratórios| Investigar cenários e identificar falhas não previstas.
🖥️ Testes de Interface (UI)| Validar elementos e comportamentos da interface.
🗄️ Testes de Dados| Verificar integridade, consistência e persistência dos dados.

⚙️ Práticas de QA

- 📋 Elaboração e execução de casos de teste.
- 🔎 Análise e validação de requisitos.
- 📝 Criação de cenários positivos, negativos e alternativos.
- 🐞 Registro, documentação e acompanhamento de defeitos.
- 📸 Coleta de evidências durante a execução dos testes.
- 🔄 Execução de testes de regressão após correções e implementações.
- 🔗 Validação de integrações e regras de negócio.
- 📊 Análise dos resultados e identificação de possíveis riscos.

🤖 Automação de Testes

- Validação de funcionalidades críticas.
- Reutilização de cenários de teste.
