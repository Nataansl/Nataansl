🧪 Testes de Software

Conhecimento em diferentes abordagens de testes para verificar funcionalidades, identificar falhas e aumentar a confiabilidade das aplicações.

🔍 Testes Funcionais

- ✅ Testes funcionais
- ✅ Testes de regras de negócio
- ✅ Testes de integração
- ✅ Testes de API
- ✅ Testes End-to-End (E2E)
- ✅ Testes de regressão
- ✅ Testes de fumaça (Smoke Tests)
- ✅ Testes de sanidade (Sanity Tests)
- ✅ Testes exploratórios
- ✅ Testes de interface (UI)
- ✅ Testes de validação de dados

⚙️ Práticas de QA

- 📋 Elaboração e execução de casos de teste
- 🔎 Análise e validação de requisitos
- 🐞 Identificação, documentação e acompanhamento de defeitos
- 🔄 Regressão após correções e novas implementações
- 🔗 Validação de integrações entre sistemas
- 🗄️ Verificação da integridade e consistência dos dados
- 📸 Registro de evidências de testes
- 📊 Análise dos resultados das execuções

🤖 Automação de Testes

- Cypress para automação de testes de interface e fluxos End-to-End
- Automação de cenários de teste repetitivos
- Validação de funcionalidades e fluxos críticos
- Identificação de falhas durante a execução dos testes
